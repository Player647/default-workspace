# default-workspace

A personal workspace connected to the DeepSeek Harness (DSH) agent.

## Contents

- `README.md` — this file
- `.gitignore` — excludes harness runtime logs and OS/editor noise

## Usage

```powershell
git clone https://github.com/Player647/default-workspace.git
```

## Notes

Harness runtime artifacts (`vmx-stdout.txt`, `vmx-stderr.txt`) are intentionally
ignored; they are per-session logs, not source.
